## 📖 Project Overview

**The Tech Chronicle** is a newspaper-inspired editorial webpage built using HTML5 and CSS3.

The project presents a technology article in a clean, publication-style layout featuring a prominent masthead, headline, subtitle, author information, featured image, readable article content, pull quote, related stories, and footer.

The design draws inspiration from traditional print newspapers while incorporating modern web design principles, including responsive typography, flexible layouts, clear visual hierarchy, and mobile-friendly styling.

This project demonstrates how fundamental front-end technologies can be used to create a structured and visually engaging editorial experience without relying on a CSS framework.

## 🎨 Design System

The project uses a restrained editorial palette inspired by print publications.

| Colour | Hex Code | Purpose |
|---|---|---|
| Warm Paper | `#FFFEFA` | Main newspaper surface |
| Page Background | `#F4F1E9` | Surrounding page background |
| Ink Black | `#191919` | Primary text |
| Editorial Red | `#A12C25` | Accent details |
| Muted Grey | `#68665F` | Supporting text |
| Divider Grey | `#C9C4B8` | Borders and separators |

### Typography

- **Playfair Display:** Publication headings, article headlines, and pull quotes.
- **Open Sans:** Body paragraphs, metadata, labels, and supporting text.

This combination creates a clear visual distinction between editorial display text and everyday reading content.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

You need:

- Visual Studio Code or another code editor.
- A modern web browser.
- An internet connection for the external fonts and featured photograph.

### 1. Clone the repository

```bash
git clone https://github.com/Regalson001/The-Tech-Chronicle-Newspaper-Layout.git
```

### 2. Navigate to the project directory

```bash
cd The-Tech-Chronicle-Newspaper-Layout
```

### 3. Open the project in VS Code

```bash
code .
```

### 4. Launch the webpage

Open `index.html` in your browser.

Alternatively, install the Live Server extension in Visual Studio Code and select **Open with Live Server**.

## 📱 Responsive Behaviour

The layout uses CSS media queries to adapt to different viewport sizes.

- **Desktop:** Spacious article layout with three related-story columns.
- **Tablet:** Adjusted content spacing and flexible typography.
- **Mobile:** Smaller headings, a single-column related-story layout, and compact metadata.

The responsive styles help maintain readability and prevent the content from overflowing on smaller screens.

## ♿ Accessibility Considerations

The project includes several accessibility-conscious practices:

- A declared document language.
- A responsive viewport setting.
- Semantic landmarks such as `main`, `header`, `article`, `section`, and `footer`.
- Logical heading structure.
- Alternative text for the featured image.
- A descriptive label for the related-stories section.
- Keyboard-visible focus styling.
- Responsive text and layouts.

Accessibility can be improved further through browser testing, keyboard navigation checks, and colour-contrast verification.

## ⚠️ Project Scope and Limitations

This is a static front-end portfolio project.

It does not currently include:

- A content management system.
- User accounts or authentication.
- A database or publishing backend.
- Dynamic article loading.
- Search functionality.
- Comments or reader interaction.
- Automated article updates.

The article content is sample editorial text created for demonstrating layout and typography. The featured image and fonts are loaded from external services and may require an internet connection.
